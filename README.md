# FAI Systems

## Starting point

Build a useful personal homebase for connecting projects, research, resources, and
workflows. Start by improving the way I work; later, explore whether the same
approach can help local small businesses and solo founders.

The first area to investigate is online presence: how people organize and
coordinate the resources and repeatable work involved in creating and maintaining
a useful web presence.

This is a working direction, not a commitment to a particular product or tech
stack. Research the problem before building integrations or a website.

## Working hypothesis

The problem may not be a lack of tools, but the friction of keeping work,
information, and next steps connected across tools. A good homebase should make
it easy to see what matters, find the right resources, and move work forward.

Test this against real workflows before treating it as fact.

## Initial tool roles

- **Notion:** projects, tasks, priorities, and operational dashboards.
- **Obsidian:** research notes, ideas, learnings, and connected reference
  material.
- **This repository:** product decisions, specifications, and any software we
  choose to build.
- **Claude Code and Codex:** coding assistants working in this repository. Keep
  important project context in versioned documentation so either tool can pick
  up the work.

Keep each piece of information's home clear. Don't automate syncing between
tools until a repeated, valuable workflow demonstrates that syncing is needed.

## First experiment

1. List the tools, documents, and recurring steps involved in one online-presence
   workflow.
2. Note where information gets lost, duplicated, or stalls.
3. Pick one frequent, frustrating handoff and try improving it with the tools
   already available.
4. Record what changed and whether it saved time or reduced confusion.
5. Only then decide whether a template, integration, or custom software is
   warranted.

## Open questions

- Which online-presence workflow is most frustrating or important to improve?
- What would make the homebase useful in everyday work?
- Which parts of the approach are relevant to local businesses or solo founders?
- What evidence would justify building a product or testing a revenue model?
